# 🩷 하츄핑 놀이터 — 색칠공부 & 따라그리기

5살 아이를 위한 **하츄핑 색칠공부·따라그리기 웹앱**입니다.
밑그림(검은 선화)은 항상 선명하게 남아 있어서, 아이가 아무리 칠해도 선이 지워지지 않습니다.

**바로 놀러 가기 → https://bbangdenge-314.github.io/hatchuping-drawing/**

---

## 🎨 두 가지 놀이

시작 화면에서 큰 버튼 두 개로 고르고, 위쪽 **🎨 색칠하기 / ✏️ 따라그리기** 버튼으로 언제든 바꿀 수 있어요.

### 1) 🎨 색칠하기 (컬러링북)
- 첫 화면부터 **진짜 하츄핑 캐릭터 선화** 가 크게 보이고 바로 색칠할 수 있어요.
- **페인트통(🪣)** 으로 영역을 톡 누르면 그 안이 싹 채워져요. (Flood Fill)
- **크레파스 / 매직펜 / 반짝이 브러시** 로 문질러 칠할 수도 있어요.
- **💡 원래 색 힌트** 를 켜면 채색된 하츄핑이 살짝 비쳐서 참고할 수 있어요. (내 마음대로 알록달록 칠해도 OK)
- 밑그림 선은 색칠 캔버스 **위에** 따로 얹혀 있어서 지우개로도 지워지지 않아요.

### 2) ✏️ 따라그리기 (단계별 밑그림)
- 연한 **밑그림** 을 따라 직접 선을 그려요.
- 4단계로 나뉘어 있어요: **① 머리 모양 → ② 얼굴 표정 → ③ 드레스와 날개 → ④ 마법봉과 구두**
  (도안마다 단계 이름이 조금씩 달라요)
- 지금 그리는 단계의 부분만 진하게 보이고, 지나온 단계는 연하게, 나머지는 아주 흐리게 깔려 있어요.
- **👀 전체 밑그림 보기** 로 모든 단계를 한 번에 볼 수 있고, **밑그림 진하기** 슬라이더로 밑그림 농도를 조절해요.

## 🖍️ 도구
- 브러시 3종: 크레파스 · 매직펜 · 반짝이(별가루)
- 굵기 3단계 (가늘게 / 보통 / 굵게)
- 지우개, 실행취소(↩), 다시 칠하기(🧼)
- 파스텔·비비드 12색 팔레트
- 스티커 도장: 하트 · 별 · 리본 · 반짝이 (터치로 콕콕, 드래그하면 줄줄이!)
- **내 그림첩 저장(localStorage) + PNG 다운로드**
- 완성하면 반짝이 폭죽과 함께 **칭찬 스티커** 를 받아요.

도안은 모두 **직접 그린 캐릭터 일러스트 선화 PNG** 입니다(`assets/`). 투명 배경에 굵고 부드러운 선이라 어떤 화면에서도 선명하게 보여요.
같은 그림의 **채색 예시 PNG**(`*-color.png`)가 힌트 레이어로 함께 들어 있습니다.

## 📱 실행 환경
- PC · 태블릿 · 스마트폰 (터치/펜 지원, `touch-action: none`)
- 모바일에서는 도구가 **화면 아래 고정 시트** 로 붙어 있어서 그림을 보면서 바로 색을 고를 수 있어요.
- 소리는 Web Audio API로 만들어 쓰기 때문에 음원 파일이 없습니다. (붓 소리 · 스티커 톡 · 완성 팡파르)

## 🛠️ 만든 방식
- 순수 HTML / CSS / JavaScript (프레임워크·빌드 없음, GitHub Pages 정적 배포)
- `index.html` · `styles.css` · `app.js` · `guides.js` · `assets/`
- 색칠 캔버스는 900×900 내부 해상도, 화면 크기와 관계없이 선명하게 렌더링
- 선화는 1200×1200 투명 PNG를 `<img>`/SVG `<image>` 레이어로 캔버스 **위에** 고정 → 색칠·지우개가 선을 건드리지 않음
- 페인트통은 선화 PNG의 **알파 채널** 을 900×900으로 래스터화해 선 마스크를 만들고(미세한 틈은 1px 두께 보정), BFS Flood Fill로 영역을 찾아 채웁니다.
  선 위를 눌러도 가까운 빈 곳을 찾아 칠해 줘요.
- 따라그리기는 같은 선화 PNG를 SVG `<mask>`(가우시안 블러로 부드러운 경계)로 단계별 영역만 밝게 보여 줍니다.
