# 🩷 하츄핑 놀이터 — 색칠공부 & 따라그리기

5살 아이를 위한 **하츄핑 색칠공부·따라그리기 웹앱**입니다.
밑그림(검은 선화)은 항상 선명하게 남아 있어서, 아이가 아무리 칠해도 선이 지워지지 않습니다.

**바로 놀러 가기 → https://bbangdenge-314.github.io/hatchuping-drawing/**

---

## 🎨 두 가지 놀이

시작 화면에서 큰 버튼 두 개로 고르고, 위쪽 **🎨 색칠하기 / ✏️ 따라그리기** 버튼으로 언제든 바꿀 수 있어요.

### 1) 🎨 색칠하기 (컬러링북)
- 첫 화면부터 **선명한 하츄핑 밑그림(검은 선화)** 이 크게 보이고 바로 색칠할 수 있어요.
- **페인트통(🪣)** 으로 영역을 톡 누르면 그 안이 싹 채워져요. (Flood Fill)
- **크레파스 / 매직펜 / 반짝이 브러시** 로 문질러 칠할 수도 있어요.
- **💡 원래 색 힌트** 를 켜면 하츄핑 원래 색이 살짝 비쳐서 참고할 수 있어요. (내 마음대로 알록달록 칠해도 OK)
- 밑그림 선은 색칠 캔버스 **위에** 따로 얹혀 있어서 지우개로도 지워지지 않아요.

### 2) ✏️ 따라그리기 (단계별 스케치)
- 연한 **분홍 점선 가이드** 를 따라 직접 선을 그려요.
- 4단계: **① 얼굴·몸 윤곽 → ② 큰 눈·입 → ③ 리본·하트 장식 → ④ 예쁘게 색칠**
- **👀 전체 밑그림 보기** 로 모든 단계를 한 번에 볼 수 있고, **밑그림 진하기** 슬라이더로 점선 농도를 조절해요.

## 🖍️ 도구
- 브러시 3종: 크레파스 · 매직펜 · 반짝이(별가루)
- 굵기 3단계 (가늘게 / 보통 / 굵게)
- 지우개, 실행취소(↩), 다시 칠하기(🧼)
- 파스텔·비비드 12색 팔레트
- 스티커 도장: 하트 · 별 · 리본 · 반짝이 (터치로 콕콕, 드래그하면 줄줄이!)
- **내 그림첩 저장(localStorage) + PNG 다운로드**
- 완성하면 반짝이 폭죽과 함께 **칭찬 스티커** 를 받아요.

## 🎮 조작법
| 하고 싶은 것 | 이렇게 |
| --- | --- |
| 색칠하기 | 색을 고르고 도형 안을 **톡** |
| 붓으로 칠하기 | 🖍️·🖊️·✨ 중 하나 고르고 손가락으로 **쓱** |
| 지우기 | 🧽 지우개 선택 후 문지르기 |
| 되돌리기 | ↩ 실행취소 |
| 도안 바꾸기 | 왼쪽(모바일은 위쪽) **도안 고르기** |
| 저장 | ⬇️ PNG 저장 / 💾 그림첩에 저장 |
| 그림첩 보기 | 🖼️ 내 그림첩 |
| 소리 끄기 | 🔊 버튼 |

## 📱 실행 환경
- PC · 태블릿 · 스마트폰 (터치/펜 지원, `touch-action: none`)
- 모바일에서는 도구가 **화면 아래 고정 시트** 로 붙어 있어서 그림을 보면서 바로 색을 고를 수 있어요.
- 소리는 Web Audio API로 만들어 쓰기 때문에 음원 파일이 없습니다. (붓 소리 · 스티커 톡 · 완성 팡파르)

## 🛠️ 만든 방식
- 순수 HTML / CSS / JavaScript (프레임워크·빌드 없음, GitHub Pages 정적 배포)
- `index.html` · `styles.css` · `app.js` · `guides.js`
- 색칠 캔버스는 900×900 내부 해상도, 화면 크기와 무관하게 선명하게 렌더링
- 선화는 SVG 레이어로 캔버스 **위에** 고정 → 색칠·지우개가 선을 건드리지 않음
- 페인트통은 선화를 오프스크린으로 래스터화한 뒤 Flood Fill(BFS)로 영역을 찾아 채웁니다.
  선 위를 눌러도 가까운 빈 곳을 찾아 칠해 줘요.

## ✅ 검증
Playwright로 PC(1440×900)와 모바일(390×844, `hasTouch: true`)에서
도안 전환 · 페인트통 채우기 · 브러시 드래그 · 스티커 · 실행취소 · 힌트 · 단계 전환 ·
완성 칭찬 · 그림첩 저장 · PNG 다운로드까지 실제 조작으로 확인했고, 콘솔·페이지 에러는 0건입니다.
